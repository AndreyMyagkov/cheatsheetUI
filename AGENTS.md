# AGENTS.md — правила работы с cheat-ui

Этот каталог — набор файлов для печатных шпаргалок A4 на базе `cheat-ui.css`.
Перед работой прочитайте `README.md` (полное описание классов, тем и печати).

## Карта файлов

| Файл | Роль |
| --- | --- |
| `cheat-ui.css` | библиотека: токены, компоненты, 4 темы, print-слой |
| `kit.html` | витрина компонентов и палитры, переключатель тем |
| `vitest_cheatsheet.html` | готовая шпаргалка, 4 листа, эталон разметки |
| `vitest_cheatsheet_ui.html` | **исходник, не трогать** |
| `README.md` | документация для человека |

Репозиторий Git отсутствует — коммиты не нужны.

## Незыблемые правила

1. **Не изменяйте `vitest_cheatsheet_ui.html`.** Это оригинал для сравнения.
2. **Контент шпаргалки 1:1.** Разрешены только исправления опечаток;
   не добавляйте и не удаляйте факты, примеры и разделы «ради красоты».
3. **Никаких новых аббревиатур в классах.** Имена читаемые:
   `.sheet-head`, `.block-title`, `.code-block`, `.callout`, `.table`, `.chip`.
   Не изобретайте `.h`, `.n`, `.tbl` и префиксы семейств.
4. **Цвет — только через токены.** У каждого акцента есть `H` и общий
   рецепт `S/L`; новый цвет = новая пара `--h-*` + `--*-soft/line`.
   Не пишите hex/rgb/css-названия цветов внутри HTML.
5. **Геометрия не зависит от темы.** Темы меняют только рецепт и поверхность;
   иначе пагинация A4 «гуляет» между темами.
6. **Один `.sheet` = одна печатная страница.** Первому листу добавьте
   `.sheet--cover`; номера в `.page-number` (`1 / 4`) обновляйте вручную.
7. **Печать перебивает темы** в слое `cheat.print` селектором
   `html, html[data-theme]`. Не выносите print-правила в `@layer cheat.themes`.

## Типовые задачи

- **Новая шпаргалка:** скопируйте структуру `vitest_cheatsheet.html`,
  подключите `cheat-ui.css`, соберите листы из `.sheet-head`, `.columns`,
  `.block accent-*`. Смотрите скил `cheat-ui`.
- **Правка оформления:** меняйте токены/компоненты в `cheat-ui.css`,
  но не меняйте размеры ради одной темы. Проверяйте `kit.html` — витрина
  должна оставаться рабочей.
- **Новый акцент:** добавьте `--h-<name>` и три переменные
  (`--<name>`, `--<name>-soft`, `--<name>-line`) в `cheat.tokens`
  и класс `.accent-<name>` по образцу соседних.
- **Проверка печати:** всегда рендерить PDF и сверять число страниц
  с числом `.sheet`. Смотрите скил `cheat-ui-print-audit`.

## Локальные скилы

- `cheat-ui` — создание листов, выбор акцентов, компоненты и темы.
- `cheat-ui-print-audit` — рендер PDF, число страниц, разрывы, подвалы.

Оба лежат в `.opencode/skills/` и подхватываются OpenCode автоматически.

## Окружение и грабли

- Windows, PowerShell 5.1: heredoc `<<` не работает. Пишите Python во
  временный `.py`-файл и запускайте `python file.py`.
- Chrome: `C:\Program Files\Google\Chrome\Application\chrome.exe`.
  Параллельные headless-запуска конфликтуют на общем профиле —
  используйте уникальный `--user-data-dir` для каждого запуска.
- PyMuPDF установлен (`import pymupdf`); скриншоты/отладочные PDF
  держите в `%TEMP%\opencode`, не замусоривайте каталог проекта.
- Счётчики `counter(page)` / `counter(pages)` в Chrome-печати дают `0 / 0`,
  поэтому подвал — обычный потоковый `.sheet-footer` с ручным номером.
- В print-слое `.columns { min-height: 710pt }` (для обложки 640pt) —
  это распорка, чтобы подвал уходил вниз. Если лист переполнен, сначала
  уплотняйте код/отступы, и только потом трогайте разрывы.
- `.code-block { break-inside: avoid }` (код не рвётся);
  `.callout { break-before: avoid }` (выноска остаётся при своём коде);
  `.block` может переходить в другую колонку — не запрещайте это.

## Definition of done

- [ ] Страниц ровно столько, сколько `.sheet`.
- [ ] На экране цветасто; в печати заливки почти белые.
- [ ] Тёмная тема печатается светлой и даёт то же число страниц.
- [ ] Код и таблицы не разрезаны между страницами.
- [ ] Подвалы у нижнего края листа, номера актуальны.
- [ ] `kit.html` открывается, все 4 темы переключаются.
- [ ] `vitest_cheatsheet_ui.html` не изменён.
