# cheat-ui: работа с китом

Кит живёт в корне проекта: `cheat-ui.css` (стили), `kit.html` (витрина),
`vitest_cheatsheet.html` (эталон разметки), `README.md` (полный справочник).
Общие правила — в `AGENTS.md`. Перед изменениями прочитайте оба файла.

## Что можно менять, а что нет

- Можно: добавлять листы и секции, назначать акценты, править компоненты
  и токены в `cheat-ui.css`, расширять витрину `kit.html`.
- Нельзя: трогать `vitest_cheatsheet_ui.html`, менять фактуру контента
  шпаргалки (только опечатки), добавлять «крипто-классы» и хардкодить цвета
  в HTML.

## Каркас нового листа

```html
<div class="sheet sheet--cover">   <!-- только первый лист -->
  <div class="cover">
    <span class="cover__eyebrow">Шпаргалка · A4 · 4 листа</span>
    <h1 class="cover__title">Тема</h1>
    <p class="cover__subtitle">Одна строка о содержимом</p>
    <div class="cover__meta"><span class="chip">v2.0</span></div>
  </div>
  <div class="columns">
    <section class="block accent-blue">
      <h3 class="block-title">Секция</h3>
      <pre class="code-block">…</pre>
      <ul class="list">…</ul>
      <p class="callout callout--info">…</p>
    </section>
  </div>
  <footer class="sheet-footer">
    <span>Тема · cheat-ui v2.0</span><span class="page-number">1 / 4</span>
  </footer>
</div>
```

Обычные листы: тот же каркас без `.cover`/`.sheet--cover`, вместо обложки —
`.sheet-head` с номером и заголовком. Внутри `.columns` секции идут
в одну колонку за другой; браузер сам балансирует две колонки.

## Выбор компонента

| Нужно | Класс |
| --- | --- |
| Заголовок листа | `.sheet-head` + `.sheet-number` + `.sheet-title` |
| Секция с цветом | `.block .accent-<name>` + `.block-title` |
| Код | `.code-block`; `<b>` — имена методов; `.tok-*` — подсветка |
| Перечисление | `.list`, `.list--check`, `.list--tight` |
| Заметка | `.callout` + `--info / --warn / --ok / --danger` |
| Сравнение/таблица | `.table` |
| Метка, клавиша | `.chip`, `.kbd` |
| Две/три карточки | `.grid-2`, `.grid-3` |

Полный список и примеры — в `README.md` и `kit.html`.

## Акценты и темы

Девять акцентов: `red, orange, amber, green, teal, cyan, blue, violet, pink`.
Класс `.accent-*` ставится на секцию, наследуется потомками и задаёт
`--c`, `--c-soft`, `--c-line`. Не задавайте цвета напрямую.

Темы: `paper` (по умолчанию), `vivid`, `muted`, `dark`. Задаются
`data-theme` на `<html>`; в `kit.html` — кнопками или `?theme=dark`.
Тема должна менять только рецепт `S/L` и поверхность, но не геометрию.
Print-правила живут в `@layer cheat.print` и перебивают любую тему.

## Новый акцент (если точно нужен)

1. В `@layer cheat.tokens` добавить `--h-<name>: <оттенок>;`.
2. Рядом добавить `--<name>`, `--<name>-soft`, `--<name>-line`
   по формуле соседних (`hsl(var(--h-<name>) var(--accent-s) var(--accent-l))`
   и т.д.), при необходимости сдвинуть L на 2–6% для жёлтых/циановых.
3. Добавить `.accent-<name>` в список классов акцента.
4. Показать новый образец в `kit.html` и описать в `README.md`.

## Проверка перед сдачей

1. Открыть страницу в браузере: на экране должно быть читаемо и цветасто.
2. Проверить печать через скил `cheat-ui-print-audit`: число страниц
   должно равняться числу `.sheet`, подвалы — у нижнего края.
3. Проверить тёмную тему: временная копия с `data-theme="dark"` должна
   печататься светлой и давать то же число страниц.
4. Убедиться, что `kit.html` не сломан и витрина показывает новый компонент.

## Частые ошибки

- `.block { break-inside: avoid }` — высокий блок целиком прыгает вниз
  и оставляет пустоту. Разрешите блоку переходить между колонками.
- Подвал через `position: fixed` + `counter(page)` — в Chrome даёт `0 / 0`.
  Используйте потоковый `.sheet-footer` с ручным номером.
- Попытка выровнять темы разными отступами/шрифтами — ломает пагинацию.
- Слишком плотный лист 2: сначала уплотните `.code-block` (font-size,
  line-height, padding), затем margins; не выкидывайте контент.
