# cheat-ui — оформление печатных шпаргалок A4

Мини-библиотека CSS для шпаргалок формата A4: на экране — ярко и цветасто,
на печати — светлые заливки, аккуратные рамки и читаемый текст.

- `cheat-ui.css` — сама библиотека (токены, компоненты, 4 темы, печать).
- `kit.html` — витрина: все компоненты, палитра и переключатель тем.
- `vitest_cheatsheet.html` — пример готовой шпаргалки на 4 листа.
- `vitest_cheatsheet_ui.html` — исходное оформление (не изменяется).

Открыть `kit.html` в браузере, переключить тему кнопками справа снизу,
нажать `Ctrl+P` — и видно, что получится на бумаге.

---

## 1. Подключение

```html
<link rel="stylesheet" href="cheat-ui.css">
```

Каркас листа:

```html
<div class="sheet">
  <div class="sheet-head accent-teal">
    <span class="sheet-number">1</span>
    <h2 class="sheet-title">Заголовок листа</h2>
  </div>

  <div class="columns">
    <section class="block accent-blue">
      <h3 class="block-title">Секция</h3>
      <pre class="code-block">…</pre>
    </section>
  </div>

  <footer class="sheet-footer">
    <span>Название · версия</span>
    <span class="page-number">1 / 4</span>
  </footer>
</div>
```

Каждый `.sheet` — отдельная страница A4: на экране это «лист» с тенью,
на печати — ровно одна страница. Первому листу (с обложкой) добавьте
`class="sheet sheet--cover"` — тогда подвал встанет ниже, с поправкой
на высоту обложки.

## 2. Компоненты

| Класс | Что это |
| --- | --- |
| `.sheet` | лист A4 (210×297 мм) |
| `.sheet--cover` | первый лист с обложкой |
| `.cover`, `.cover__eyebrow`, `.cover__title`, `.cover__subtitle`, `.cover__meta` | шапка-обложка |
| `.sheet-head`, `.sheet-number`, `.sheet-title` | плашка заголовка листа |
| `.columns` | две колонки с разделителем |
| `.block` | секция; цвет задаётся классом `.accent-*` |
| `.block-title`, `.block-title__hint` | заголовок секции и подсказка справа |
| `.code-block` | блок кода (не рвётся между страницами) |
| `.list`, `.list--check`, `.list--tight` | списки: квадратик, галочка, плотный |
| `.callout`, `.callout__title` | выноска; модификаторы `--info/--warn/--ok/--danger` |
| `.table` | таблица с зеброй |
| `.chip`, `.chip--ok`, `.chip--bad` | «таблетки»-метки |
| `.kbd` | клавиша |
| `.grid-2`, `.grid-3` | сетки на 2 и 3 колонки |
| `.text-muted`, `.text-small` | утилиты |
| `.sheet-footer`, `.page-number` | подвал листа и номер страницы |

Подсветка кода внутри `.code-block`:

```html
<span class="tok-comment">// комментарий</span>
<span class="tok-string">'строка'</span>
<span class="tok-number">42</span>
<span class="tok-keyword">const</span>
<span class="tok-builtin">vi.fn</span>
<span class="tok-function">expect</span>
```

Полный набор примеров — в `kit.html`.

## 3. Акценты

Девять оттенков, у каждого три варианта: `--c` (текст и линии),
`--c-soft` (заливка), `--c-line` (рамка). Класс ставится на контейнер
и наследуется детьми.

```
.accent-red    .accent-orange .accent-amber
.accent-green  .accent-teal   .accent-cyan
.accent-blue   .accent-violet .accent-pink
```

```html
<section class="block accent-violet">…</section>
```

Внутри секции всё красится автоматически: заголовок, рамка кода,
маркеры списка, выноска по умолчанию. Выноску можно перекрасить
модификатором (`.callout--warn`) независимо от секции.

## 4. Темы

Тема задаётся атрибутом на `<html>`:

| Тема | Значение | Вид |
| --- | --- | --- |
| paper | без атрибута (по умолчанию) | светлая, пастельные заливки |
| vivid | `data-theme="vivid"` | максимально яркая |
| muted | `data-theme="muted"` | приглушённая, почти монохром |
| dark | `data-theme="dark"` | тёмная инверсия для экрана |

```html
<html lang="ru" data-theme="dark">
```

В `kit.html` тему можно передать ссылкой: `kit.html?theme=dark`
или переключить кнопками (выбор запоминается в `localStorage`).

Печать всегда светлая: `@layer cheat.print` перебивает любую тему,
от цвета остаётся только оттенок `H`.

---

## 5. Как устроен цвет

Цвет — это оттенок `H` плюс общий рецепт насыщенности и светлоты:

```css
--h-blue: 218;

--blue:      hsl(var(--h-blue) var(--accent-s) var(--accent-l));
--blue-soft: hsl(var(--h-blue) var(--soft-s)   var(--soft-l));
--blue-line: hsl(var(--h-blue) var(--line-s)   var(--line-l));
```

- `--accent-s/l` — насыщенный цвет текста и линий;
- `--soft-s/l` — заливка (на экране пастель, на печати почти белая);
- `--line-s/l` — рамки и разделители.

Темы и печать меняют только эти пять переменных — поэтому пагинация
не зависит от темы, а цвета остаются согласованными.

У жёлтого, циана и зелёного светлота чуть сдвинута (`calc(... - 2…6%)`),
иначе они выглядят светлее остальных при том же `L`.

**Добавить свой оттенок:** объявите `--h-lilac: 290;` и три переменные
по образцу соседних, затем класс `.accent-lilac`.

## 6. Печать

- Формат A4, поля `@page { size: A4; margin: 10mm }` — поэтому отступы
  есть и на страницах-продолжениях, а не только на первом листе.
- Каждый `.sheet` начинается с новой страницы; подвал прижат к низу.
- Заголовки, код, выноски, таблицы и пункты списков не разрываются
  между страницами; выноска остаётся при своём коде.
- **В диалоге печати включите «Фон и изображения»** (Background graphics),
  иначе заливки и плашки не напечатаются.
- Номер страницы в подвале — обычный текст (`1 / 4`), его нужно
  поправить вручную при изменении числа листов: Chrome в headless-печати
  не считает `counter(page)` (выдаёт `0 / 0`).

Ориентир по высоте: при полях 10 мм полезная высота ≈ 785 pt.
В print-слое `.columns { min-height: 710pt }` — это «распорка», чтобы
подвал вставал вниз на недозаполненных листах. Если контент листа
выше — уменьшайте отступы и код, иначе появятся лишние страницы.

## 7. Рецепт новой шпаргалки

1. Скопируйте `vitest_cheatsheet.html` в новый файл.
2. Оставьте `<link rel="stylesheet" href="cheat-ui.css">`.
3. На первом листе: `.sheet.sheet--cover` + `.cover` с заголовком
   и чипами.
4. Остальные листы: `.sheet` → `.sheet-head accent-*` → `.columns`.
5. Каждую смысловую секцию — в `<section class="block accent-*">`
   со своим цветом; внутри: `.block-title`, `.code-block`, `.list`,
   `.callout`, `.table`.
6. Обновите `.page-number` и текст подвала.
7. Проверьте печать: `Ctrl+P` → «Фон и изображения» → число страниц
   должно совпасть с числом `.sheet`.

Совет: держите один лист = одна тема. Так проще найти нужное
на бумаге и не ломать пагинацию при правках.
